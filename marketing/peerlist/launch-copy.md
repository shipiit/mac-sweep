## Tagline

## Project description
MacSweep brings disk cleanup, system monitoring, security checks, developer tools, and AI usage insights into one native SwiftUI app for macOS.

Explore storage down to individual folders, review cleanup recommendations, find duplicates, and understand which processes are using CPU and memory. Inspect app permissions, completed downloads, and network connections. For development, see listening ports with their project paths and commands, manage local services, and review Docker, Homebrew, Xcode, and dependency storage.

Track Claude Code and Codex usage by model, project, and session, including API-equivalent cost estimates and available limit information. A menu bar popover and expandable notch HUD keep useful details close to your workflow.

Built for macOS 15+ and Apple Silicon, with on-device analysis, no analytics, and no third-party dependencies. Cleanup recommendations include context, protected-path checks, and Trash-by-default behavior.

Explore the interactive showcase: https://shipiit.github.io/mac-sweep-website/

Current access: the showcase is public; app source and release downloads require access to the private app repository.
